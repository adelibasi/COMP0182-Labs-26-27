# COMP0182 – Real-World Multi-Agent Systems

ROS 2 Humble and TurtleBot3, taught as a progressive path from software fundamentals to real physical robots — building confidence with ROS 2 in simulation, then carrying the same workflows onto physical robots.

The labs live in numbered folders (`1/`, `2/`, …), one per session, each with its own README.

Labs are released here week by week; only the labs covered so far are published.

## Roadmap

- **Phase 1 — ROS 2 foundations:** nodes, topics, services, actions
- **Phase 2 — Real robot fundamentals:** TF2, odometry, Python nodes, closed-loop control
- **Phase 3 — SLAM and navigation:** mapping and localisation
- **Phase 4 — Multi-robot systems:** namespaces, multi-robot coordination
- **Phase 5 — Challenge:** an end-to-end multi-robot task on physical TurtleBot3s

This is a high-level outline and may evolve — see each lab's own README for what it actually covers.
